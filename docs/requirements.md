# 需求文档

## 1. 项目概述

`football-predict` 是一个足球数据的 **RAG 知识库 + 比赛预测 + 统计分析** Web 服务。目标是把足球相关数据（比赛记录、球队/球员信息、历史战绩等）沉淀为可检索的知识库，并用自然语言问答、结果预测、统计报表三种方式对外提供价值。

## 2. 目标用户

- 足球数据分析爱好者
- 需要快速查询球队/球员/联赛数据的用户
- 希望基于历史数据做比赛预测或统计的开发者

## 3. 功能需求

### FR-1 RAG 知识库问答
- 用户用自然语言提问（如「上赛季谁夺冠了」「曼城主场胜率多少」）
- 系统检索相关知识片段，结合 LLM 生成回答
- 回答需附带检索来源，便于追溯

### FR-2 比赛结果预测
- 输入主队、客队，输出胜/平/负三类概率与预测结论
- 基于历史比赛数据（当前为启发式，后续可替换 ML 模型）

### FR-3 统计分析与报表
- 查询某球队的基础统计（场次、胜场、进球、失球、净胜球）
- 后续扩展：联赛积分榜、进球效率、主客场对比

### FR-4 数据导入与管理
- 支持导入文本到向量库（自动分块 + MD5 去重）
- 支持列出已导入的来源、按来源删除、清空向量库

### FR-5 Web 交互
- 提供 FastAPI 后端 API 与 Streamlit 前端界面
- 前端三个 Tab：RAG 问答 / 比赛预测 / 统计分析

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 单次检索 + 生成回答在数秒内完成 |
| 可扩展 | 预测/统计模块留接口，便于替换为 ML 模型 |
| 易用 | 无需命令行，通过浏览器界面即可使用 |
| 数据安全 | 数据存本机，向量库本地持久化 |
| 可维护 | 配置集中管理（`Settings`），模块职责单一 |

## 5. 数据需求

- **比赛记录**：`home_team / away_team / home_goals / away_goals`（详见 `data-format.md`）
- **知识库文本**：任意描述性文本（球队介绍、球员数据、赛程等）
