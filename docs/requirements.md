# 需求文档

## 1. 项目概述

`football-predict` 是一个足球数据的 **采集 + 预测 + 统计分析 + 对话式 agent** Web 服务。从 500 彩票网足彩页采集比赛、赔率、球员数据，用泊松模型预测比赛结果，并通过 DeepSeek 对话式 agent 对外提供自然语言预测问答。

## 2. 目标用户

- 足球数据分析爱好者
- 需要查询球队/球员数据、做比赛预测的用户
- 希望基于历史数据做预测或统计的开发者

## 3. 功能需求

### FR-1 数据采集
- 爬取 500 彩票网足彩数据：比赛（全场/半场比分）、胜平负赔率、球队名、球员阵容
- 按期号批量采集历史数据与未来赛事（未开赛）
- 球队名规范化（ID → 完整名）+ 别名映射（简称/全名统一）
- 排除国家队/世界杯比赛，只保留俱乐部赛事

### FR-2 比赛预测
- 输入主队、客队，输出胜/平/负概率、期望进球、最可能比分、大小球概率
- 支持赔率融合（欧赔隐含概率 + 泊松概率加权）
- 支持让球盘（给定让球数算让球胜平负）

### FR-3 对话式预测 agent
- 用自然语言提问（如「皇马 vs 巴萨谁赢」），agent 自动查数据 + 跑模型给出分析
- 支持多轮追问（结合上下文）
- 预测时可结合球队统计、历史交锋、球员阵容等因素

### FR-4 统计分析与报表
- 球队统计（场次/胜平负/进球/失球/场均进球/场均失球）
- 联赛积分榜（含联赛维度、按积分排序）

### FR-5 Web 交互
- 提供 FastAPI 后端 API 与 Streamlit 前端界面
- 前端 4 个 Tab：数据总览 / 智能预测 / 球员阵容 / 统计分析

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 单次预测在数秒内完成；agent 对话在可接受延迟内返回 |
| 可扩展 | 预测模块留接口，便于替换模型；采集层便于新增数据源 |
| 易用 | 浏览器界面即可使用 |
| 数据安全 | 数据存本机，SQLite 本地持久化 |
| 可维护 | 配置集中管理，模块职责单一（一文件一职责） |

## 5. 数据需求

- **比赛记录**：`home_team / away_team / home_goals / away_goals / home_halftime / away_halftime / status` 等
- **赔率**：`home_win / draw / away_win`（欧赔 1X2）
- **球员**：`name / number / position / nationality / age / height / weight / market_value / appearances / goals / assists`
